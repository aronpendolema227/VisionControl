# VisionControl

**VisionControl** es una aplicación web full stack para la gestión, control y seguimiento de cámaras de videovigilancia.  
El sistema permite administrar inventario de cámaras, reportes técnicos, convenios, usuarios, roles y auditorías, manteniendo trazabilidad de las acciones realizadas dentro de la plataforma.

## Tecnologías utilizadas

### Frontend
- React
- Vite
- JavaScript
- CSS
- React Icons
- Axios

### Backend
- Java 17
- Spring Boot
- Spring Security
- JWT
- Maven
- JPA / Hibernate

### Base de datos
- PostgreSQL
